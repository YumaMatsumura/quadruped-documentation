# DC-DCコンバータの選定

DC-DCコンバータは、出力電圧だけでなく以下を確認する。

- [ ] 入力電圧範囲
- [ ] 最大入力電圧
- [ ] 出力電圧
- [ ] 連続出力電力
- [ ] 最大出力電流
- [ ] 変換効率
- [ ] 温度ディレーティング
- [ ] 冷却方法
- [ ] 出力リップル
- [ ] 過電圧保護（OVP）
- [ ] 過電流保護（OCP）
- [ ] 過熱保護（OTP）

!!! note
    入力電圧範囲は「40Vに対応している」だけではなく、満充電時の電圧やモータ回生・サージによる電圧上昇も考慮して選定する。

## Jetson用DC-DCコンバータ

設計条件は以下とする。

| 項目 | 設計条件 |
| --- | --- |
| 入力 | 40Vmaxバッテリ対応 |
| 出力 | 19V |
| 負荷側設計上限 | 66.5W |
| 設計余裕 | 20%以上 |
| 出力電力候補 | 80〜100W級 |

## GL-MT3600BE用USB-PD電源

設計条件は以下とする。

| 項目 | 設計条件 |
| --- | --- |
| 入力 | 40Vmaxバッテリ対応 |
| 出力 | USB-PD |
| 負荷側最大電力 | 12W未満 |
| 候補 | 30W以上 |

出力電力だけでなく、5V/3A、9V/3A、12V/2.5Aなど、ルータが対応するPDプロファイルを供給できることを確認する。

## MID-360・冷却ファン用DC-DCコンバータ

必要電力は、

\[
14
+
P_{\mathrm{fan,max}}
\]

で求める。  
25%の余裕を持たせる場合、

\[
P_{\mathrm{DC-DC}}
\ge
\left(
14 + P_{\mathrm{fan,max}}
\right)
\times 1.25
\]

とする。  
ファン選定後、この式から必要なDC-DCコンバータ容量を算出する。
