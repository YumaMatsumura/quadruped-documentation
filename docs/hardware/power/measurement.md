# 電力計測

設計時の電力見積もりを実測値へ更新するため、
バッテリー側の電圧・電流を計測する。

## 計測項目

以下の状態で計測を行う。

1. Jetsonアイドル
2. Jetson高負荷時
3. モータ立位時
4. 歩行時
