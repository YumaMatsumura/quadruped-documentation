# 電源設計

本章では、四脚ロボットに搭載する各機器の消費電力を整理し、以下の選定に必要となる電力・エネルギーを見積もる。

- バッテリ
- DC-DCコンバータ
- ヒューズ
- コンタクタ
- 配線・コネクタ

以下の2構成を対象とする。

1. 【構成1】RobStride Edulite 05 x 4
2. 【構成2】RobStride 02 x 12

## 電源構成

現在想定している電源構成を以下に示す。

バッテリには、マキタ40Vmaxシリーズの使用を検討している。  
40Vmaxは満充電時の電圧を表しており、公称電圧は36Vとして扱う。  
したがって、エネルギー容量の計算では**36V**を使用する。

!!! note
    電源機器を選定するときは、公称36Vだけでなく、満充電時の40Vやモータ回生時の電圧上昇も考慮する必要がある。

## 電源設計で使用する値

電源設計では、主に以下の3つの値を使用する。

| 項目 | 単位 | 主な用途 |
| --- | --- | --- |
| 電力 | W | DC-DCコンバータ、ヒューズ、配線などの選定 |
| 電流 | A | ヒューズ、配線、コネクタ、コンタクタの選定 |
| エネルギー | Wh | バッテリ容量、稼働時間の計算 |

### 電力

電力は以下で求める。

\[
P = V\times I
\]

- \(P\)：電力 [W]
- \(V\)：電圧 [V]
- \(I\)：電流 [A]

!!! example
    19Vで3A消費する機器の場合、\(19 \times 3 = 57W\)となる。

### エネルギー

バッテリ容量を考える場合は、電力ではなくエネルギーを使用する。

\[
E = P_{\mathrm{avg}} \times t
\]

- \(E\)：エネルギー [Wh]
- \(P_{\mathrm{avg}}\)：平均消費電力 [W]
- \(t\)：使用時間 [h]

!!! example
    平均200W消費するロボットを30分動作させる場合、\(200 \times 0.5 = 100Wh\)が必要になる。

!!! note
    同じ機器でも、用途によって見る電力が異なる。

    | 値 | 使用目的 |
    | --- | --- |
    | 平均電力 | バッテリ容量・稼働時間の計算 |
    | 最大電力 | DC-DCコンバータ・ヒューズ・配線などの選定 |
    | 瞬間最大電力 | モータ、バッテリ、BMSなどのピーク性能確認 |

    例えばJetsonが通常40W程度で動作していたとしても、高負荷時に60W消費する可能性がある場合、バッテリ容量計算では平均40Wを使用するが、DC-DCコンバータは60W以上を供給できるものが必要になる。

## 共通機器

### Jetson Orin Nano Super

Jetson Orin Nano Superは、推論処理やGPUを使用した高負荷処理を行うことを想定する。  
また、以下を使用する前提とする。

```bash
sudo nvpmodel
sudo jetson_clocks
```

電力モードとして`MAXN SUPER`を使用する場合も想定する。

NVIDIAの開発者キットではDCジャックから給電し、DCジャックの最大電流仕様は3.5Aである。  
19V給電とした場合、\(19 \times 3.5 = 66.5W\)となる。

したがって、DC-DCコンバータについては最低限この電力を供給できるようにする。

| 項目 | 値 |
| --- | --- |
| 出力電圧 | 19V |
| 平均消費電力 | 実測予定 |
| 電源設計上限 | 最大焼く66.5W |
| DC-DCコンバータ候補 | 19V/80~100W級 |
| 給電方法 | DCジャック |

!!! note
    Jetsonの電力モードで指定されるW数はSoC/モジュール側の電力管理値であり、開発者キット全体の入力電力と同じではない。  
    NVMe、USB-CAN FD変換器、USB機器などの消費電力も考慮する必要があるため、実機ではバッテリ側の消費電力を測定する。

### GL.iNet GL-MT3600BE

仕様は以下の通り。

| 項目 | 値 |
| --- | --- |
| 電源 | USB Type-C PD |
| 対応電圧 | 5V/3A、9V/3A、12V/2.5A |
| 消費電力 | 12W未満 |

DC-DCコンバータ/USB-PD給電は、余裕を持たせて**30W以上**を選定候補とする。  
GL-MT3600BEの公式仕様では、消費電力は12W未満となっている。

### Livox MID-360

仕様は以下の通り。

| 項目 | 値 |
| --- | --- |
| 入力電圧 | 9~27V DC |
| 平均消費電力 | 6.5W |
| 低温時ピーク | 最大14W |

※通常時の平均消費電力は6.5Wであるが、低温時の自己加熱では最大14Wになる場合がある。

### 冷却ファン

仕様は以下の通り。

| 項目 | 値 |
| --- | --- |
| 電圧 | TBD |
| 平均電力 | TBD |
| 最大電力 | TBD |
| 電流 | TBD |

MID-360と冷却ファンを同一DC-DCコンバータから給電する場合、

\[
P_{\mathrm{DC-DC}} = P_{\mathrm{MID360,max}} + P_{\mathrm{Fan,max}}
\]

を満たすDC-DCコンバータを選定する。  
さらに20~30%程度の余裕をもたせる。

## 【構成1】EduLite 05 x 4

仕様は以下の通り。

| 項目 | 1台 |
| --- | --- |
| 定格電圧 | 48V |
| 入力電圧範囲 | 15~60V |
| 定格出力 | 19W±10% |
| 定格トルク | 1.8Nm |
| 最大トルク | 6Nm |

4台使用する場合の定格機械出力は、\(19 \times 4 = 76W\)となる。  
ただし、この**76Wはモータ軸から出力される機械出力**であり、バッテリから消費する電力ではない。

モータ・ドライバ効率を\(\eta_{\mathrm{motor}}\)とすると、

\[
\frac{P_{\mathrm{motor,output}}}
{\eta_{\mathrm{motor}}}
\]

となる。

例えば、初期見積もりとして効率を80～85%と仮定した場合、

\[
\frac{76}{0.8 \sim 0.85}
\simeq
89 \sim 95W
\]

となる。

したがって、定格運転時の参考値としては、**約90~95W**程度の電気入力になると仮定できる。

!!! warning
    これはバッテリ選定のための暫定値であり、実際の歩行時の平均電力やピーク電力ではない。  
    四脚ロボットでは各関節の負荷が常に一定ではないため、実機完成後にモータ電源バスの電圧・電流を測定する。

### 電力収支

| 機器 | 数量 | 平均電力 | 設計最大電力 | 備考 |
| --- | --- | --- | --- | --- |
| EduLite 05 | 4 | 要実測 | 定格入力参考値：約90~95W | バッテリ直結 |
| Jetson Orin Nano Super | 1 | 要実測 | ~66.5W | MAXN SUPER想定 |
| GL-MT3600BE | 1 | 要実測 | 12W | USB-PD |
| MID-360 | 1 | 6.5W | 14W | 低温時ピーク考慮 |
| 冷却ファン | 1 | TBD | TBD | 選定後記入 |
| その他制御機器 | - | TBD | TBD | モニタ、リレー等 |

ここで求めたい値は、

\[
P_{\mathrm{motor,avg}}
+
P_{\mathrm{Jetson,avg}}
+
P_{\mathrm{router,avg}}
+
P_{\mathrm{MID360,avg}}
+
P_{\mathrm{fan,avg}}
+
P_{\mathrm{other,avg}}
\]

である。  
この値を実測し、バッテリ容量計算に使用する。

## 【構成2】RS02 x 12

仕様は以下の通り。

| 項目 | 1台 |
| --- | --- |
| 定格電圧 | 48V |
| 入力電圧範囲 | 24~60V |
| 定格出力 | 170W±10% |
| 定格トルク | 6Nm |
| 最大トルク | 17Nm |

12台使用する場合の定格機械出力は、\(170 \times 12 = 2040W\)となる。  
ただし、この**2040Wはモータ軸から出力される機械出力**であり、バッテリから消費する電力ではない。

初期見積もりとして効率を80～85%と仮定した場合、

\[
\frac{2040}{0.8 \sim 0.85}
\simeq
2400 \sim 2550W
\]

となる。

したがって、定格運転時の参考値としては、**約2.4~2.55kW**程度の電気入力になると仮定できる。

### バッテリ電流の目安

マキタ40Vmaxを公称36Vとして考えると、

\[
I = \frac{P}{V}
\]

より、

\[
\frac{2400}{36}
\simeq
66.7A
\]

\[
\frac{2550}{36}
\simeq
70.8A
\]

となる。  
したがって、12軸すべてが定格出力付近で動作した場合、**約67~71A**程度のバッテリ電流になる可能性がある。

!!! warning
    これは「12軸すべてが定格出力付近」という条件での参考値である。  
    実際の歩行時の平均電力はこれより低くなる可能性がある一方、加速・着地・姿勢復帰などでは短時間のピークが発生する。  
  RS02の仕様に記載されている「相電流」を、そのままバッテリー電流として計算してはいけない。

### 電力収支

| 機器 | 数量 | 平均電力 | 設計最大電力 | 備考 |
| --- | --- | --- | --- | --- |
| RS02 | 12 | 要実測 | 定格入力参考値：約2.4~2.55kW | バッテリ直結 |
| Jetson Orin Nano Super | 1 | 要実測 | ~66.5W | MAXN SUPER想定 |
| GL-MT3600BE | 1 | 要実測 | 12W | USB-PD |
| MID-360 | 1 | 6.5W | 14W | 低温時ピーク考慮 |
| 冷却ファン | 1 | TBD | TBD | 選定後記入 |
| その他制御機器 | - | TBD | TBD | モニタ、リレー等 |

この構成では、補機系よりも**モータの消費電力が圧倒的に大きい**ため、バッテリ選定では特に以下を確認する。

- バッテリ容量 [Wh]
- 連続放電可能電力 [W]
- 連続放電可能電流 [A]
- 瞬間最大放電電流 [A]
- BMSの保護特性
- 回生時の挙動

## DC-DCコンバータの選定

DC-DCコンバータは単純に出力電圧だけで選定せず、以下を確認する。

- [ ] 入力電圧範囲：40Vmaxバッテリに対応していること
- [ ] 出力電圧：接続機器の要求電圧
- [ ] 連続出力電力：最大消費電力以上
- [ ] 最大出力電流：接続機器の最大電流以上
- [ ] 変換効率：バッテリ消費電力計算に使用
- [ ] 温度ディレーティング：高温時にも必要出力を確保できること
- [ ] 冷却方法：自然空冷・強制空冷
- [ ] 出力リップル：Jetsonやセンサへの影響を確保
- [ ] 保護機能：OVP、OCP、OTP等

DC-DCコンバータには20~30%程度の余裕をもたせる。

### Jetson用DC-DCコンバータ

現在の候補仕様は以下とする。

- 入力：40Vmaxバッテリ対応
- 出力：19V
- 出力電力：80~100W級

### MID-360・冷却ファン用DC-DCコンバータ

現在の候補仕様は以下とする。

- 入力：40Vmaxバッテリ対応
- 出力：24V

必要電力は、

\[
P_{\mathrm{MID360,max}}
+
P_{\mathrm{fan,max}}
\]

で求める。  
さらに余裕を1.25倍とすると、

\[
P_{\mathrm{DC-DC}}
\ge
P_{\mathrm{required}}
\times 1.25
\]

程度を目安とする。

### DC-DCコンバータ損失を含めたバッテリ消費電力

例えばDC-DCコンバータ効率が90%の場合、

\[
\frac{P_{\mathrm{load}}}{0.9}
\]

となる。

!!! example
    Jetsonが60W消費した場合、66.7Wをバッテリ側から消費する。  
    そのため、最終的な電力収支表では**DC-DCコンバータ変換損失も含めて計算する。**

## バッテリ容量の計算

バッテリ公称エネルギーは、

\[
V_{\mathrm{nominal}}
\times
C
\]

で求める。  
マキタ40Vmaxの場合は、公称36Vとして計算する。  
例えば4Ahの場合、144Whとなる。

### マキタ40Vmaxの容量比較

| バッテリ | 容量 | 公称エネルギー |
| --- | --- | --- |
| BL4040F | 4.0Ah | 約144Wh |
| BL4050F | 5.0Ah | 約180Wh |
| BL4080F | 8.0Ah | 約288Wh |
| BL4080H | 8.0Ah | 約288Wh |

マキタ40Vmaxの「40V」は満充電時の電圧であり、公称電圧は36Vとして扱う。

### 使用可能エネルギー

バッテリは公称容量を100%使い切る前提にしない。  
使用率を\(k\)とすると、

\[
E_{\mathrm{battery}}
\times k
\]

となる。  
初期検討では、例えば

\[
k=0.8
\]

として80%程度を使用可能エネルギーと仮定する。  
BL4040Fの場合、115.2Whとなる。

### 稼働時間

ロボット全体の平均消費電力がわかれば、

\[
\frac{E_{\mathrm{usable}}}{P_{\mathrm{total,avg}}}
\]

で稼働時間を求められる。  
例えばBL4040Fを使用し、平均消費電力が200Wだった場合、0.576hとなるため、

\[
0.576 \times 60
\simeq
35min
\]

程度となる。

!!! note
    バッテリー容量 [Wh]だけでバッテリーを選定してはいけない。  
    モータでは大電流が流れるため、必要なWhを満たしていても、バッテリーの最大出力W・AやBMSの制限によって使用できない場合がある。

## 実機で測定する項目

特にモータの平均消費電力は仕様書だけでは正確に決定できない。  
そのため、初期構成のEduLite 05 x4を製作した段階で、電圧・電流モニタを使用して以下を測定する。

| 条件 | 測定項目 |
| --- | --- |
| 電源ON・待機状態 | 電圧、平均電流、平均電力 |
| Jetsonアイドル | 平均電力 |
| MAXN SUPER + `jetson_clocks` | 平均・最大電力 |
| GPU推論実行中 | 平均・最大電力 |
| MID-360・ルータ動作中 | 平均電力 |
| モータ無負荷動作 | 平均・最大電力 |
| ロボット立位 | 平均・最大電力 |
| 歩行 | 平均・最大電力 |
| 急加速・急停止 | ピーク電力 |
| 長時間歩行 | 消費エネルギー [Wh] |

最終的には、

- 平均電力 → バッテリ容量・稼働時間
- 最大電力 → DC-DCコンバータ・バッテリ出力
- 最大電流 → ヒューズ・配線・コネクタ・コンタクタ
- ピーク電圧 → 放電モジュール・耐圧

という形で各部品の選定に使用する。

## 選定の進め方

電源系の部品は以下の順番で選定する。

1. 各機器の電圧・電力仕様を整理する
2. DC-DCコンバータの必要出力電力を決める
3. 初期構成で実際の平均・最大電力を測定する
4. ロボット全体の平均消費電力を算出する
5. 必要な稼働時間を決める
6. 必要なバッテリー容量 [Wh]を求める
7. バッテリーの最大出力W・Aを確認する
8. 最大電流からヒューズ・配線・コネクタを選定する
9. コンタクタ・プリチャージ回路・放電モジュールを選定する

!!! important
    四脚ロボットでは、バッテリ容量より先に「モータが要求する瞬間電力をバッテリーが供給できるか」を確認する必要がある。  
    特にRS02 ×12構成ではkW級の電力になるため、容量 [Wh] と出力性能 [W / A] の両方を確認する。
